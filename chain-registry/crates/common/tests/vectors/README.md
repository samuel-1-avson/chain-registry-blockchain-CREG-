## Extracted subsets

- `mldsa44_keygen_acvp.json`: first 5 `ML-DSA-44` (`tgId = 1`) key generation cases (`tcId` 1–5).
- `mldsa44_siggen_acvp.json`: first 5 `ML-DSA-44` deterministic pure external cases (`tgId = 1`, `tcId` 1–5, covering both empty and non-empty `context`) plus first 2 `ML-DSA-44` hedged pure external cases (`tgId = 13`, `tcId` 181–182, with explicit `rnd` and `context`).
- `mldsa44_sigver_acvp.json`: all 15 `ML-DSA-44` pure external verification cases (`tgId = 1`, `tcId` 1–15, covering 3 passing and 12 failing vectors across empty and non-empty `context`).
