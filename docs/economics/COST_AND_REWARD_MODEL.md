# Cost and reward model

The MVP uses fiat subscriptions, stablecoins, prepaid credits, grants, and
enterprise sponsorship. A native tradable token is outside the security path.

## Metered cost dimensions

Admission, CPU minutes, peak memory, sandbox time, build time, storage and
replication, egress, licensed tools, human review, monitoring, incident
response, retention, and support are recorded per job/profile/tenant.

Price = measured resource cost + retention/availability margin + support tier.
Validator/reviewer compensation is paid from priced work or an explicit grant,
not an assumed token price. Bonds cover objectively defined liabilities and
remain locked through the challenge window. A token is reconsidered only after
independent operators, real demand, enforceable slashing, separated governance,
and legal review exist.
