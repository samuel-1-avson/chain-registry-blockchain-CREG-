# Incident response

`detect → preserve evidence → assign commander → contain narrowly → rotate affected trust root → notify → recover in stages → postmortem`.

Runbooks cover malicious qualification, publisher/validator/governance key
compromise, split-view, sandbox escape, storage loss, queue overload, database
corruption, vulnerability-feed poisoning, client rollback, and settlement
outage. Each drill records detection, decision, containment, revocation
propagation, recovery, preserved evidence, lessons, and follow-up owner.

Emergency revocation is narrow, expiring, multi-party, and available while the
system is paused. It cannot publish, upgrade policy, move treasury, or erase
history.
