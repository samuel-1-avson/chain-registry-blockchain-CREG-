# Dispute process

1. Challenger submits a signed subject, claim, evidence digest, and bond.
2. The package controller responds with counter-evidence and provenance.
3. Independent reviewers reproduce or challenge the evidence under a named profile.
4. An adjudication council issues a bounded decision with reasons and conflicts.
5. The log records challenge, response, decision, bond outcome, and any supersession.
6. Sensitive exploit details remain off-chain until safe disclosure; immutable
   state stores only necessary commitments.

AI/LLM output is advisory evidence only and can never be final adjudication.
