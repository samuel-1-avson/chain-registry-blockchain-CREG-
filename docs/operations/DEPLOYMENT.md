# Deployment model

Phase 0 runs only a coordinated research alpha. Production-like deployments
must use signed configuration, pinned images/dependencies, KMS/HSM keys,
separate public query and authenticated submission planes, isolated workers,
rate limits, quotas, immutable object retention, and multi-domain replication.

The capability matrix must report validator/witness count, control domains,
enabled profiles, disabled research features, contract addresses, and audit
state. A deployed contract or running node does not by itself establish a
production claim.
